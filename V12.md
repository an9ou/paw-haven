# Paw Haven v1.2: build contract (laptop only, fast)

Read this together with API.md, API_v2.md and TREASURE.md. Where they disagree, this file wins.

**Target:** desktop or laptop at 1280×720 and up. No phone work.

**The build:** the coordinator merges everything into one Artifact page:

> game (`game/paw_haven_proto.html`) + `/*@@PAWART@@*/` = dogs + world_a + world_b, and `/*@@PAWMODS@@*/` = mods/pawaudio.js + mods/walkrun.js + mods/toys.js

The game agent must add this line exactly once, right after the pawart script and before the game script:
`<script id="pawmods">/*@@PAWMODS@@*/</script>`

## What the client asked for in v1.2
1. **Feeding:** the bowl shows the EXACT food chosen, not a generic bowl.
2. **Real time and weather:** the clock and the visuals must match. No sun at 03:14, no sunny yard when it says rainy.
3. **Raincoats and weather reactions:** different raincoats for the dogs, and different reactions to each action depending on weather and time of day.
4. **Interactive toys:** every bought toy can be played with directly.
5. **Walk as a runner mini-game:**
   - Reference: endless-runner games like Gingerbread-man runners.
   - Props sit at different heights. The dog must JUMP, keep WALKING or CROUCH to grab items or avoid obstacles.
   - Long jumps clear puddles, which keeps the dog clean.
   - Readable timing and a fair success rate, logical and creative. It keeps the v1.1 treasure hunt.
6. **Cozy music:**
   - Relaxing, chill and generative.
   - Different music per place, time, weather and activity, all in ONE consistent style, with smooth changes that aren't obvious.
   - Full sound settings, as in other games.
7. **Design only (no code):** a farming and garden system plus a cooking system, which give the yard's veggie patch a use. These go in the proposal doc.

## Time and weather model (shared names)
- **`time`:** `'dawn'` (05:00–06:59) | `'day'` (07:00–16:59) | `'dusk'` (17:00–18:59) | `'night'` (19:00–04:59)
- **`weather`:** `'sunny'` (a clear sky; at night that means a clear sky with stars) | `'cloudy'` | `'rain'` | `'snow'`
- **Clock:** the clock follows the player's REAL local device time.
- **Weather:** seeded by the real date, with 3 weather periods per day (00–08, 08–16, 16–24). Snow only happens in Dec–Feb in the northern-hemisphere default; otherwise the roll is rain. Rough odds: sunny 45%, cloudy 25%, rain 25%, snow 5% (snow only in winter).
- **Stat decay:** keeps the prototype speed setting, separate from the clock.
- **Dev panel:** add "Time override" (auto / dawn / day / dusk / night) and "Weather override" (auto / sunny / cloudy / rain / snow).

## Art additions

**World A (`PawArt.scene` and `PawArt.walkStrip`):**
- Accept `{time, weather}` options, defaulting to day/sunny. `scene` keeps `locked` and `bonds` for the map.
- Each time and weather combination is drawn properly, not just tinted:
  - **Sky:** dawn peach-pink, day blue, dusk orange-lilac, night deep navy with pencil-hatched sky and stars.
  - **Sun and moon:** the sun appears only in dawn, day and dusk (low at dawn and dusk); the moon and stars at night.
  - **Night details:** lit windows and glowing street lamps.
  - **Cloudy / rain:** grey clouds; the sun hidden or peeking.
  - **Rain:** wet ground sheen and puddles.
  - **Snow:** snow caps on roofs, fences and trees, and white ground patches.
- The game adds moving rain and snow particles on top, so the art must not include falling drops.
- Cache per combination.

## Module interfaces (plain IIFE scripts, no imports; each attaches ONE global)

### `mods/walkrun.js` → `window.PawWalk`
```
PawWalk.start(el, o) → controller { stop() }   // renders the whole walk UI inside el (absolutely-positioned container filling the stage below the HUD)
o = {
  area: 'park'|'river'|'woods'|'beach', time, weather,
  dog: { key, name, outfit },                 // outfit = {head,eyes,neck,body}
  abilities: { extraDig, goggles, necklace, poncho, clover, luckyPenny, raincoat, rainHat, warm },  // booleans from equipment
  durationSec: 75, firstWalk: bool,
  rollTreasure: (area) => ({ name, rarity, kind, desc } | { coins, text }),   // game's loot logic; call once when the correct X is dug (and for the bonus sparkle)
  junk: () => ({ text, coins }),              // wrong-dig consolation
  bag: [{ name, count }],  useBagItem: (name) => bool,   // e.g. Wild Berries: +15 s
  sfx: (name) => void,   say: (text, ms) => void,   // speech bubble near the dog (module may also draw its own)
  onEnd: (r) => void
}
r = { coins, treasure, bonus, junk: [..], digsUsed, happiness, bond, energy, cleanliness, obstaclesHit, cleanRun, distance, puddlesCleared }
```
- The module owns the gameplay: an auto-run runner with parallax tiled `walkStrip(area, {time, weather})`, obstacles, items at 3 heights, the Nose-o-meter, dig spots, the bag, a timer, results data, keyboard (Space/↑ jump, hold for a long jump; ↓/S crouch; D dig; B bag; Esc pause) and on-screen buttons. It never touches localStorage or game state directly. It reports through `onEnd`. The game applies everything.
- It must work with `el` sized about 1240×620.
- No fail state: bumping an obstacle means a stumble with a small penalty and a funny line, and the run continues.

### `mods/toys.js` → `window.PawToys`
```
PawToys.supports(name) → bool
PawToys.open(el, name, ctx) → controller { close() }
ctx = { dog: { key, name, outfit }, time, weather, sfx, say, reward: ({ happiness, bond, coins, energy }) => void, onClose: () => void }
```
- Toys: Tennis Ball, Rope Tug, Squeaky Duck, Frisbee, Plush Bone, Puzzle Feeder, Driftwood Stick, Rubber Chicken, Glow Ball.
- Each is a short (20–60 s), direct, mouse-driven interaction with the dog. The game applies the rewards with its own daily diminishing returns.

### `mods/pawaudio.js` → `window.PawAudio`
```
PawAudio.init()                       // call on first user gesture; idempotent; creates AudioContext
PawAudio.ctx, PawAudio.bus = { master, music, sfx, ambience }   // GainNodes; the game routes its SFX into bus.sfx
PawAudio.setContext({ place, area, time, weather })   // place: 'title'|'yard'|'shelter'|'market'|'shop'|'map'|'walk'|'fetch'|'toy'|'bath'|'sleep'|'journal'|'wardrobe'
PawAudio.setVolumes({ master, music, sfx, ambience })  // 0..1 each
PawAudio.getVolumes(); PawAudio.setMuted(bool); PawAudio.isMuted()
PawAudio.duck(amount = 0.5, ms = 1500)  // briefly lower music (level-up fanfare, treasure reveal)
PawAudio.stinger(name)  // optional short musical cue in the same style: 'treasure','levelup','adopt'
```
- Everything is generated live (WebAudio synthesis, no files) and CPU-light.
- One consistent lo-fi, cozy style across every variant.
- Variants change smoothly, on bar boundaries, with crossfades of about 4–6 s.
