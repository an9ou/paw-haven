# Paw Haven v2.1: Sparkle & Family (desktop only, 1280×720)

Read `PIPELINE.md` first: worktrees, lanes and tests. Then read `V2.md`, `V2_GENES.md` and `docs/design/02-v2-playdates-sparkle.md` (the "Sparkle", "Journal" and "Economy" sections). **Where this file disagrees with older docs, this file wins.**

v2.1 builds the parts of the v2 design that v2 left out:

- the Sparkle boosts and the Sparkle Meter;
- the Stone hint;
- ancestry and grand-mixes;
- the collection rewards (titles, the Rainbow Collar, yard decorations);
- the pen-pal postcard schedule;
- the Gene Sniffer and the town painter.

It also fixes five open `TODO.md` items. No new place, no new save version.

## Standing rules (every lane)

- **Nothing bad ever happens.** There are no fail states, no sickness and no running away. A blocked action gets a short, kind, two-sentence explanation.
- **No selling dogs, ever.**
  - Puppies are adopted out free to named families.
  - **Sparkle is cosmetic only.** It is never sold, never in a shop, never boosted with coins, and gives no stat, coin, Bond or litter bonus.
  - Reward items (Rainbow Collar, Giant Crayon Box, Family Photo Frame, Doggy Ramp, Rocking Chair) never appear in any shop.
- **Real welfare.** Every v2 playdate rule stays: always 4 legs, real habits and real breeding rules.
- **Words.** Never use "breed" as a verb, or "stud", "litter price", "sell" (for dogs) or "stock". No franchise names: the build rejects "nintendo", "pokémon" and "animal crossing".
  - Use: Puppy Playdate, Family Tree, in season, Expecting, adopting out, pen-pal family.
- **Copy style.** Plain, short English: one idea per sentence, no semicolons in player-facing text, no emoji in code (use icons). Jokes are welcome. Tips are two sentences at most.
- **UI.** Every window is a centred popup (`openModal`). Motion respects `[data-motion="off"]`.
- **Economy.** Walks stay the main income (about 100 a day). New coin rewards are one-time, or small and capped.
- **Save.** `S.v` stays 1. Every new field is optional, and every reader defaults it.
  - There is no CORE lane in v2.1, so each lane defaults its own fields on `game:ready` inside its own files (as `13b_breeding.js` does today). `00_core.js` is not touched.
- **Shared scope.** Every `game/src` file shares one scope.
  - Prefix new top-level names with your lane tag: `gn` GENES, `br` BREED, `jr` JOURNAL, `tw` TOWN, `hm` HOME. Only the cross-lane API names in section 2 are unprefixed.
  - Before committing, grep the whole of `game/src` for every new top-level name.
- **Cross-lane calls** are always guarded: `if (typeof fn === 'function') fn(...)`. Read the data model directly where you can.

## 3. GENES lane (`mods/genes.js`, pure and additive)

**`ancestry(rec, lookup, depth = 6)`** returns `{ breedKey: fraction }`.

- `lookup(id)` returns a record with `{ key, mix, parents, anc? }`, or null.
- If `rec.anc` exists, return it unchanged.
- If both parents resolve: the average of the two parents' ancestry, computed recursively and memoised by id. Stop at `depth`; a cut-off parent counts as the base case below.
- Base case, no parents:
  - a dog with `mix: { a, b }`: `{ a: 0.5, b: 0.5 }`;
  - a dog with no mix: `{ key: 1 }`.
- Unknown keys count as `'mutt'`. Round fractions to multiples of 1/64, so the output is stable.

**`grandMix(anc)`** returns `{ kind, name, label, breeds: [[key, frac], ...] }`. `breeds` are sorted by share. The first matching rule wins:

1. **Everything Dog:** 4 or more breeds at 12.5% or more each.
   - `kind: 'everything'`, `name: 'The Everything Dog'`.
2. **Grand-mix:** 3 or more breeds at 25% or more each. `kind: 'grand'`.
   - The name comes from the top three breeds:
     - Corgi + Husky + Dachshund: **Sled Noodle**
     - Shiba + Corgi + Golden: **Sunrise Loaf**
     - Golden + Husky + Mutt: **Snowdrift**
   - Otherwise `'<Top breed> family mix'` (`kind: 'family'`).
3. **Mostly one breed:** the top breed is 75% or more. `kind: 'breed'`, `name` = the breed name.
   - The label notes the rest in fractions, for example "Corgi, 1/4 Husky".
4. **Two-breed mix:** the top two breeds are each 25% or more.
   - `kind: 'mix'`, `name: MIXES[mixKey(a, b)].name`, label "Horgi: Corgi × Husky".
5. **Anything else:** `'<Top breed> family mix'` (`kind: 'family'`).

`label` is always a ready-to-print line:

- "Sled Noodle: Corgi + Husky + Dachshund"
- "The Everything Dog: yes."
- "Corgi, 1/4 Husky"

**`sparkleOdds(o)`** returns `{ p, mult, parts: [{ label, x }], text }`.

- `o = { stone: bool, sparkleParents: 0|1|2, bondA, bondB, base = 1/512 }`.
- Boosts multiply together:
  - Sparkle Stone: ×4;
  - each Sparkle parent: ×1.5;
  - both parents at Bond 10: ×2;
  - otherwise, both parents at Bond 8 or more: ×1.5.
- `text` reads like "1 in 64 today: Sparkle Stone ×4, Bond 10 ×2". With no boosts it is "1 in 512".
- The pity guarantee (24th puppy) stays in BREED.

- Each lane writes its suite with `game/test_lib.js`. Use crafted saves and no real-day waits.
- Run your own suite plus `smoke` before committing: `node game/run_tests.js smoke game/test_v21_<lane>.js --jobs 1`.
  - In this cloud container, set `PAW_ARGS=--ignore-certificate-errors` and `NODE_PATH=$(npm root -g)`.
- **Merge order** (coordinator, `tools/wt.sh merge <name>`, smoke after each):
  1. GENES
  2. WORLD ART
  3. DOG ART
  4. BREED
  5. JOURNAL
  6. TOWN
  7. HOME
- **After merging:**
  - an integration review (cross-lane names and fields, duplicate top-level names in `game/src`);
  - a copy check against the standing rules;
  - fixes;
  - `node game/run_tests.js all --jobs 2` plus the v21 suites;
  - updating `CHANGELOG.md` and `TODO.md`.
