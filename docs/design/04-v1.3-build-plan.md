## Scope: MVP first

The v1.3 MVP keeps every system that makes the garden and kitchen feel alive (weather, seasons, dog perks, stars, safety) and trims the quantity: 6 plots, 6 crops, 6 recipes and one mini-game mechanic. Everything cut is content or polish that can drop in later without a save change.

### How it fits the places system

- **Garden at ****`yard`****.** A new hotspot on the yard's veggie patch opens the garden view. The action bar stays at 7 buttons.
- **Kitchen at ****`house`****.** A hotspot on the house's kitchen corner opens the kitchen view.
- **Pip's Sprout Cart at ****`market`****.** A 4th clickable shop, `data-shop="sprout"`, sits in the Market Street foreground.
- **Away from home.** Tapping Garden or Kitchen in the Journal from another place says "The garden is at home" and offers "Go home", like the Care tray.
- **Crops grow everywhere.** Growth runs on the real clock no matter where the dog is.
- **Dishes are portable.** The Feed tray at every place shows a Dishes row.
- **Unlocks.** New players get the garden at Bond 2 and the kitchen at Bond 3. Existing saves get both on first load, with a gift of 3 carrot seeds and 3 pea seeds from Pip.

## Module plan

The game stays the integrator: it owns the save, inventory, coins, buffs, hotspots, Pip's shop, the Feed tray and the Journal. Two new plain-IIFE modules own their own views and rules, the same way PawWalk owns the runner. The exact contract, with every table, is in /home/claude/proto/V13.md.

| Part | Owns | Never touches |
| --- | --- | --- |
| Game (`game/paw_haven_proto.html`) | `S` and its migration, the 60-second garden tick, hotspots, Pip's Sprout Cart modal, the Kibble Corner pantry, eating dishes, buffs and limits, walk hooks, Journal tabs, safety junk finds, the dev panel, audio contexts | Growth maths, the mini-game |
| `mods/garden.js` → `window.PawGarden` | Crop data, the pure growth model (`advance`, `plant`, `water`, `harvest`), Buddy perks, the squirrel, the garden view | localStorage, coins, inventory |
| `mods/kitchen.js` → `window.PawKitchen` | Recipe, pantry and People-food data, `match`, `hint`, `dishStars`, the recipe book, ingredient picker, People pantry shelf, the mini-game, the reveal card | localStorage, eating, buffs |

### PawGarden interface

```
PawGarden.CROPS, PawGarden.BUDDY
PawGarden.newState() → GardenState            // 6 empty plots
PawGarden.periodKey(date) → 'YYYY-M-D-p'     // same as the game's weather period key
PawGarden.advance(state, ctx) → { state, events }   // PURE
  ctx = { now, weatherAt(key), buddy, maxPeriods: 90, steps: 0, stepWeather: 'cloudy', rng? }
  events = [{ type: 'ready'|'squirrel'|'tend', plot, crop }]
PawGarden.plant(state, i, cropId, { month }) → { state, ok, bonusSeed }   // PURE
PawGarden.water(state, i) → state                                         // PURE
PawGarden.harvest(state, i, ctx) → { state, items: [{ crop, stars }], took } // PURE
PawGarden.open(el, o) → { close(), update(partial) }
  o = { state, time, weather, month, dog, buddy, seeds, sfx, say,
        onPlant(i, cropId) → bool, onHarvest(i, items, took), onBonusSeed(cropId),
        onChange(state), onClose() }
```

Each weather period, rain refills every plot to 3 drops. A watered crop then grows by season × weather ÷ (days × 3) and uses 1 drop (2 on a sunny day period, 0 in rain or snow). A dry crop just waits and counts a dry period. Catch-up stops at 90 periods, and a clock moved backwards does nothing.

### PawKitchen interface

```
PawKitchen.RECIPES, PawKitchen.PANTRY, PawKitchen.PEOPLE_FOOD, PawKitchen.FAV
PawKitchen.match(ids) → recipeId | null           // order-free exact multiset
PawKitchen.hint(ids, known) → string | null        // "Close! Two of those belong together."
PawKitchen.dishStars(cookStars, cropStars[]) → 1..3   // ceil((cook + average crop stars) / 2)
PawKitchen.open(el, o) → { close(), update(partial) }
  o = { dog, time, weather, known, best, pantry, crops, fridge: { count, max: 8 }, sfx, say,
        onCook({ recipe, used, cookStars, stars, auto, discovered }), onSafety(foodId), onClose() }
```

The mini-game is one mechanic: a needle sweeps a dial once in 1.6 seconds, and the player taps in the golden zone (25% of the arc for 1- or 2-step dishes, 15% for 3 steps). Each step scores 0 to 2. The cooking stars are 3 at 80% or more of the maximum, 2 at 40% or more, otherwise 1.

### What the game wires up

1. **Tick.** On load, on tab focus and every 60 seconds, call `PawGarden.advance` with the game's seeded weather for each period key; turn events into toasts.
2. **Hotspots.** `data-hot="garden"` in `yard`, `data-hot="kitchen"` in `house`, `data-shop="sprout"` in `market`; pass `scene('yard', { patch: 'empty'|'growing'|'ready' })`.
3. **Eating.** The Dishes row in Feed applies the effect × star multiplier (1, 1.25, 1.5) and the favourite bonus, sets `S.buff`, and enforces 2 dishes a day and 1 Bond dish a day.
4. **Buff hooks.** `walk15` adds 15 seconds to the next walk's `durationSec`; `dig1` sets `abilities.extraDig` on the next walk; `cool` multiplies walk Energy by 0.75 and skips the hot penalty for 24 hours; `warm` makes `isWarm()` true and halves Happiness decay for 24 hours.
5. **Fallback.** If a module is missing or throws, the hotspot shows "The garden is having a nap" and nothing crashes.

No new hub scene is needed for the places system. The two module views use new full-view scenes, `garden` and `kitchen`, behind them.

**Migration of a v1.2.1 save** (inside the existing `migrate()`):

1. If `S.garden` is missing, create every field above with its default.
2. Set `S.gkEarly = true`, so the garden and kitchen open at once instead of at Bond 2 and 3.
3. Show one toast: "Pip left a packet of seeds on your doorstep. The veggie patch is yours now!"
4. Run `PawGarden.advance` once; with `last` set to now, nothing grows yet.

If `PawGarden` is missing at load, the game writes the same default garden itself, so a save never breaks when a module fails to load.

## Test plan

The coordinator runs one automated Playwright playthrough on the merged build at 1280 × 720 and one Node balance script; v1.3 is ready for the client when every box below is ticked and no console error appears.

**Automated playthrough** (dev panel controls drive time and weather)

- A new save: the garden hotspot says "opens at Bond 2" and the kitchen hotspot "opens at Bond 3".
- A v1.2.1 save loads with 6 empty plots, 3 carrot and 3 pea seeds, the Pip toast, and both hotspots open.
- The garden hotspot works only at `yard`, and the kitchen only at `house`; elsewhere the Journal buttons offer "Go home".
- Pip's cart: buying Pumpkin Seeds takes 20 coins; the People rack shows the onion note and cannot be bought.
- Plant carrot in plot 1 (Noodle plants in one tap); water it to 3 drops.
- 9 cloudy periods with daily watering make the carrot ready, and a ready toast appears.
- One rain period refills every plot to 3 drops.
- Snow pauses carrot growth; spinach grows at half speed; with Frost, carrot grows at half speed.
- A sunny day period uses 2 drops and grows 1.5 × faster.
- A dry plot droops, counts a dry period and never loses its crop.
- Harvesting gives 2 carrots with stars; the Garden tab count goes up by 2.
- After 3 ready periods the squirrel takes 1 item and leaves an IOU; with Biscuit it never does.
- Blueberries go back to leafy after harvest and are ready again 3 days later.
- Selling carrots pays 10, 15 or 20 by stars.
- Cooking Carrot Crunchies runs 2 dial steps and puts the dish in the fridge; eating it shows a buff chip and the next walk gets 15 extra seconds.
- Pumpkin, oats and egg discover Pumpkin Pupcake with a NEW stamp; a wrong mix makes Mystery Mush with a hint.
- Tapping Chocolate on the People pantry shows its note; it never reaches the pot.
- A 3rd dish in one day is refused with the treats line; a 2nd Bond dish gives no Bond.
- With 8 dishes in the fridge, Cook is disabled.
- A walk junk Onion shows its safety note, pays 5 coins and adds no item.
- Reload mid-growth keeps every plot; moving the clock back grows nothing; a 40-day jump grows at most 90 periods.
- Screenshots of the garden, kitchen, mini-game, Pip's cart and both Journal tabs in day, night, rain and snow.

**Build risks**

| Risk | Mitigation |
| --- | --- |
| World B's art volume (33 items, 13 icons, 24 crop drawings) slips | World B starts first with the crop prop; modules build on stubs and swap in art last |
| Real-time growth is slow to test | `advance` takes `steps` and `stepWeather`; the dev panel has "+1 period" and "All ready" |
| Clock exploits or long absences | Catch-up stops at 90 periods; a clock moved backwards grows nothing |
| A module fails to load | The hotspot says "The garden is having a nap"; the game writes a default garden itself |
| Garden income creeps above walks | The balance script fails the build above 45 coins a day |
| Favourite dishes differ from the full design because 11 recipes wait | V13.md lists MVP stand-ins; the full favourites return when those recipes ship |
