# The first three Instagram posts

Two versions, same story. Pick one (or ask me to mix them).

- **Version A: the 3-tile banner.** One wide picture cut into 3 tiles. Post them the same morning.
- **Version B: three separate posts.** One idea each, posted on different days.

All images are 1080 x 1350 (4:5). Files are in `brand/instagram/launch/`. Important parts sit in the centre 3:4 area so the profile grid crop (about 34 px off each side) never cuts anything that matters.

Captions use the owner's rules: no "ugliest", never "breed" as a verb, no "sell" for dogs. Instagram **alt text** is kept under 100 characters (the limit I know of; the app will tell you if not).
