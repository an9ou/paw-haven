## Real (ranked)
1. **The wheel words and the card name still use a system font in ja/zh-Hans/zh-Hant/ko/th** (art must-fix 1 isn't working). CDP shows ja IPAPGothic, zh WenQuanYi Zen Hei, ko WenQuanYi, th Loma; the buttons next to them use Klee One / LXGW / Iansui / Poor Story / Mali. Cause: world/pawart_world_b.js:7046 injects `.pa-wb text{font-family:'Caveat',cursive}`, and that rule beats the font-family attribute that 50_friends.js:174 and :201 set (FR_FONT :181). The v219 test only reads getAttribute, so it passes. Shots: out/zoom/ja_360_wheels.png, out/shots/ja_360_04_*. Fix: write `style="font-family:${FR_FONT}"` on both `<text>`s (an inline style wins), or change the rule to `.pa-wb text:not([font-family])`. Test with getComputedStyle().fontFamily. The same rule also hides FONT_L on Dog Card text (world_b :3371 cardF). Then re-measure item 7 and the wheel squeezes (ja/th/de/pt-BR words get squeezed today).
2. **The invite page header tabs break letter by letter at 1024 and 1280** in 10 of 11 languages (de "St/ar/t", "Hu/nd/e"; pt-BR and id up to 5 lines; only en fits). MEASURE can't see it because nothing overflows. The header sits inside the 716 px `.sheet.prose` (tools/site_i18n.js:367, site/style.css:44), but its tabs use the wide row layout (style.css:263-265). /privacy has the same markup and the same break, which existed before this release. Shots: out/zoom/ja_360_row.png, ja_360_giftgrid.png, out/shots/ja_360_12_*, ja_360_32_*. Fix: frPairName (50_friends.js:63) puts U+200B between the two words when fr.name has no space (ja, zh, th); drop keep-all; use `overflow-wrap:break-word;line-break:strict` on .fr-nm/.fr-prev/.fr-gnm/.mb-t b.
