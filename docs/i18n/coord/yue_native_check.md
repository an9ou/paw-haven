# Cantonese (yue): lines for a native speaker to check

For the owner's friend, a native Hong Kong speaker, before Cantonese ships. Each row is one choice the translators were unsure of. Please answer in the last column: "OK", or a better wording. The game is for children, so the words must be kind and simple. Keys are for the developers; the English is the original.

Collected from the six chunk term lists (`docs/i18n/coord/yue_terms_c1.md` … `c6.md`) and `docs/i18n/yue.md` section 14. Where a key has `*`, the same word is used in all keys of that pattern; the example shows the first one.
