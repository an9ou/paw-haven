# Paw Haven v1.3, "Garden & Kitchen" update: build contract (laptop only, fast)

Read this with V12.md and V121.md, which still apply except where this file overrides them. The full design is the "Garden & Kitchen" tab of the proposal doc, and the plan is its "v1.3 build plan" tab. **Where they disagree, this file wins.**

**Status:** ready to build. Do NOT start until the coordinator says go.

**Target:** desktop or laptop at 1280×720 and up. No phone work.

**The build:** the coordinator merges everything into one Artifact page:

> game (`game/paw_haven_proto.html`) + `/*@@PAWART@@*/` = dogs + world_a + world_b, and `/*@@PAWMODS@@*/` = mods/pawaudio.js + mods/walkrun.js + mods/toys.js + **mods/garden.js + mods/kitchen.js**

## What the client asked for
1. **Give the yard's veggie patch a use.** Players farm in the garden.
2. **Cooking:** the crops make foods for the dogs.
3. **Dog safety:** the game never lets a player plant or cook anything toxic to dogs, and it explains why in a kind way.

## MVP scope (v1.3)
**In v1.3:**
- 6 plots on the yard veggie patch, fixed (no expansions).
- 6 crops, 6 recipes.
- One mini-game mechanic: tap when the needle is in the golden zone. It is drawn as chop, stir, bake, simmer or chill.
- Pip's Sprout Cart on Market Street.
- Seasons by real month (northern hemisphere).
- Weather-driven growth and watering.
- 6 Garden Buddy perks.
- One pest: Captain Fluff the squirrel.
- 1–3 quality stars.
- The full dog-safety rules.
- Two new Journal tabs: Garden and Recipes.
- A fridge of 8 dishes, and dish buffs.

**Not in v1.3:**
- Plot expansions.
- The other 6 crops.
- The other 11 recipes.
- Compost and Worm Tea.
- Raven, slugs and weeds.
- Big can, Sprinkler, Cold Frame and Scarecrow.
- Giant crops.
- A hemisphere setting.
- Recipe cards on walks, and Pip's recipe gifts.
- Dish spoilage.
- Carry and guard poses.

## Growth model (PawGarden owns it; it is pure and deterministic)

**Periods.** These are the v1.2 weather periods: 00–08, 08–16 and 16–24, with key `YYYY-M-D-p`, p = 0, 1, 2. That is the same format as the game's `weatherPeriodKey()`.

`advance()` walks every period from `state.last` (exclusive) up to the current period (inclusive). It processes at most `maxPeriods`, default 90 (30 days). For each period, take `w = weatherAt(key)`:

1. **Rain:** every plot's `water` becomes 3.
2. **Each plot with a growing crop** (`g < 1`):
   - **If `water ≥ 1`:**
     - Growth: `g += season × weather / (days × 3)`.
       - `season` = 1 if the period's month is in the crop's seasons, otherwise 0.5.
       - `weather`: sunny in p = 1 or 2 is 1.5. Sunny in p = 0 (clear night), cloudy and rain are 1. Snow is 0.
       - Snow exceptions: snow is 0.5 if the crop is hardy, or if `buddy === 'snow'`.
     - Water used: sunny in p = 1 or 2 uses 2. Cloudy and sunny in p = 0 use 1. Rain uses 0. Snow uses 0.
     - Clamp `water` to ≥ 0.
   - **Else** (no water): `dry += 1` and the crop does not grow. It never dies.
   - **Mochi:** if `buddy === 'inspect'`, set `inspected = true`.
   - **Ready:** when `g ≥ 1`, set `g = 1`, set `ready = key`, and emit `{type: 'ready', plot}`.
3. **Each ready plot:**
   - Count the periods since it became ready.
   - At 3 periods, if `buddy !== 'guard'` and `took === 0`: set `took = 1` and emit `{type: 'squirrel', plot}`.
4. **Pepper (`buddy === 'tend'`):** the first plot that reaches `water = 0` in a calendar day gets `water = 1`. Emit `{type: 'tend', plot}`.

**Stage from `g`:**

| g | Stage |
|---|---|
| 0 | 0 (seed) |
| > 0 and < 0.4 | 1 (sprout) |
| ≥ 0.4 and < 1 | 2 (leafy) |
| 1 | 3 (ready) |

`dry` = true for the prop when `water === 0` and the crop is not ready.

**Harvest:**
- **Items:** `yield − took` items, minimum 1.
- **Quality points (0–3):** +1 if `dry === 0`, +1 if it was planted in season (`inSeason`), +1 if `inspected`.
- **Each item rolls its stars** from the table below.

| Quality points | 1★ | 2★ | 3★ |
|---|---|---|---|
| 0 | 70% | 25% | 5% |
| 1 | 55% | 35% | 10% |
| 2 | 40% | 40% | 20% |
| 3 | 25% | 45% | 30% |

- **Regrow:** blueberries do not reset to empty after harvest. They get `g = 1 − regrow / days` (= 0.4), `ready = null`, `took = 0`, `dry = 0`.
- **Everything else:** the plot becomes empty.

**Clock safety:**
- If the current key is earlier than `state.last` (the clock went back), do nothing.
- Never process more than `maxPeriods`.

**RNG:** stars and Noodle's bonus seed use `ctx.rng` when it is given. Otherwise use a seeded RNG from (plot index, planted key, harvest count), so tests are reproducible.

**Garden Buddy perks:** `buddy` comes from the dog key.

| key | buddy | perk |
|---|---|---|
| `dachs` | `dig` | Planting is 1 tap (no dig step), and each planting has a 1 in 10 chance of `onBonusSeed(cropId)`. |
| `corgi` | `guard` | The squirrel never takes anything. |
| `golden` | `fetch` | The Basket harvests every ready plot in one tap. |
| `shiba` | `inspect` | +1 quality point (it sets `inspected`). |
| `husky` | `snow` | Snow slows growth to 0.5 instead of pausing it. |
| `mutt` | `tend` | MVP stand-in until compost ships: one plot a day never fully dries (see step 4). |

## Module interfaces (plain IIFE scripts, no imports; each attaches ONE global)

### `mods/garden.js` → `window.PawGarden`
```
PawGarden.CROPS                         // the crop table above, as objects: {id, name, seasons:[], days, regrow|null, yield, seed, sell, hardy, seedItem, item}
PawGarden.BUDDY                         // {shiba:'inspect', corgi:'guard', golden:'fetch', dachs:'dig', husky:'snow', mutt:'tend'}
PawGarden.newState() → GardenState      // 6 empty plots, last = current period key
PawGarden.periodKey(date) → 'YYYY-M-D-p'
PawGarden.stage(plot) → 0|1|2|3
PawGarden.advance(state, ctx) → { state, events }   // PURE: never touches DOM or localStorage; returns a NEW state object
ctx = {
  now: Date.now(),                      // ms
  weatherAt: (key) => 'sunny'|'cloudy'|'rain'|'snow',   // the game's seeded weather for any period key (it respects dev overrides only for the current period)
  buddy: 'inspect'|'guard'|'fetch'|'dig'|'snow'|'tend'|null,
  maxPeriods: 90,
  steps: 0,                             // DEV/TEST: if > 0, advance exactly this many periods from state.last, using stepWeather instead of weatherAt
  stepWeather: 'cloudy',
  rng: undefined                        // optional () => [0,1)
}
events = [{ type: 'ready'|'squirrel'|'tend', plot: index, crop: id }]

PawGarden.harvest(state, plotIndex, ctx) → { state, items: [{crop, stars}], took }   // PURE
PawGarden.plant(state, plotIndex, cropId, ctx) → { state, ok, bonusSeed }          // PURE; ctx.month: 1–12 (sets inSeason)
PawGarden.water(state, plotIndex) → state                                          // PURE; water = 3

PawGarden.open(el, o) → controller { close(), update(partial) }
o = {
  state,                                 // GardenState (the module clones it)
  time, weather, month,                  // current env
  dog: { key, name, outfit }, buddy,
  seeds: { carrot: 3, peas: 3, ... },    // owned seed counts by crop id
  sfx: (name) => void, say: (text, ms) => void,
  onPlant: (plot, cropId) => bool,       // game spends 1 seed; returns false when none (module shows "No seeds: Pip's Sprout Cart is on Market Street")
  onHarvest: (plot, items, took) => void,// game adds items to S.inv.crops and S.garden.harvests
  onBonusSeed: (cropId) => void,
  onChange: (state) => void,             // called after EVERY change (plant, water, harvest); game stores S.garden = state and saves
  onClose: () => void
}
controller.update({ state, time, weather, seeds })   // the game calls this every 60 s while open (after its own advance) and after weather changes
```
**What the module owns:**
- The garden view in `el` (about 1240×620):
  - `PawArt.scene('garden', {time, weather})` as the background.
  - The 6 plots drawn at the scene's plot zones with `PawArt.prop('plot', {water})` and `PawArt.prop('crop', {crop, stage, dry})`.
  - 0–3 water-drop dots under each plot, using `icon('drop')`, with empty drops as outlines.
  - A sparkle on ready plots.
  - The dog at the dog spot: `PawArt.dog(key, {pose})`. The pose is `dig` when planting, `happy` on harvest, `idle` otherwise, and `cold` / `hot` follow the v1.2 weather rules.
  - Weather particles are drawn by the module (simple CSS drops or flakes), because the garden is outdoors.
- **A tool bar** with Seeds, Watering Can and Basket, plus a weather chip and the Buddy tag (dog head and perk text).
- **The seed pouch:**
  - It lists owned seeds, with in-season seeds first and an "In season" stamp.
  - Planting an off-season seed asks once per session: "This grows at half speed now. Plant anyway?"
- **Squirrel:**
  - When a `squirrel` event is pending for an open plot, it plays a short Captain Fluff run-by (`prop('squirrel')`).
  - The plot then shows `prop('iou')` until it is harvested.
- **Speech lines:** one perk line per dog, plus at least 8 garden jokes ("The peas are thinking about it.").
- **Keyboard:** 1–6 select a plot; P plants; W waters; H harvests; Esc closes.
- **No fail state:** nothing is ever destroyed.

**Robustness:**
- An unknown crop id is ignored.
- A missing PawArt name shows the "?" placeholder.
- The module must never throw from `open` with a valid `o`.

### `mods/kitchen.js` → `window.PawKitchen`
```
PawKitchen.RECIPES                      // the recipe table above: {id, name, ingredients:[ids], steps:['chop'|'stir'|'bake'|'simmer'|'chill'], effect:{hunger,happy,energy,bond,buff:null|{id:'walk15'|'cool'|'warm'|'dig1', hours|walks}}, unlock:'start'|'experiment', hint}
PawKitchen.PANTRY                       // the pantry table above
PawKitchen.PEOPLE_FOOD                  // the safety table above
PawKitchen.FAV                          // the favourites table above

PawKitchen.hint(ids, known) → string|null   // "Close! Two of those belong together." when an UNKNOWN recipe shares ≥ 2 ingredients
PawKitchen.dishStars(cookStars, cropStars[]) → 1..3   // ceil((cookStars + average(cropStars)) / 2); pantry items carry no stars
PawKitchen.open(el, o) → controller { close(), update(partial) }
o = {
  dog: { key, name, outfit }, time, weather,
  known: ['carrot-crunchies', 'chicken-veggie-rice', 'blueberry-pupsicle'],
  best: { 'carrot-crunchies': 2 },       // best stars per recipe (3 enables "Cook by heart")
  pantry: { oats: 4, rice: 2, egg: 1, chicken: 0 },   // water is always available
  crops: { carrot: [1, 2, 0], peas: [3, 0, 0] },      // counts by star [1★, 2★, 3★]
  fridge: { count: 2, max: 8 },
  sfx, say,
  onCook: (r) => void,    // r = { recipe: id|'mystery-mush', used: [{id, stars|null}], cookStars: 1..3, stars: 1..3, auto: bool, discovered: bool }
  onSafety: (foodId) => void,
  onClose: () => void
}
```
**What the module owns:**
- **The kitchen view:** `PawArt.scene('kitchen', {time, weather})`, with no particles because it is indoors.
- **The recipe book:**
  - It shows known recipes as cards (`prop('recipe-card')`) and unknown ones as pencil silhouettes with their `hint` and ingredient count.
  - A missing ingredient greys out and says where to buy it ("Kibble Corner pantry" or "grow it").
- **The pantry shelf:** ingredient icons with counts. Crops always use the highest stars first.
- **The People pantry shelf:** greyed out, with a paw-stop badge (`icon('paw-stop')`).
  - A tap shows the `PEOPLE_FOOD` note and calls `onSafety`.
  - The item never enters the pot.
- **Experiment:** drop 2–4 ingredients in the pot.
  - A match goes to the mini-game, and `discovered` is true if it was unknown.
  - No match makes Mystery Mush (no mini-game), plus `hint()`.
- **The mini-game:** one mechanic for every step.
  - A needle sweeps once across `prop('dial')` in 1.6 s. The player taps (click or Space) when it is in the golden zone.
  - Zone width: 25% of the arc for recipes with 1–2 steps, 15% for 3 steps.
  - The doodle beside the dial shows the step: `prop('board')` for chop, `prop('pot')` for stir and simmer, `prop('oven')` for bake, a frost doodle for chill.
  - Step score: 2 inside the centre half of the zone, 1 inside the zone, 0 outside or no tap.
  - `cookStars`: 3 if the total is at least 80% of the maximum, 2 if at least 40%, otherwise 1.
  - The dog sits in the `beg` pose and says one line per step.
  - No fail: the worst result is 1★ with a joke ("It's... a shape. Biscuit loves it anyway.").
- **Cook by heart:** if `best[id] === 3`, a button skips the mini-game and gives `stars = 2`, `auto = true`.
- **Full fridge:** if `fridge.count >= fridge.max`, Cook is disabled with "The fridge is full. Feed a dish first."
- **The reveal card:** `prop('bowl', {food: dish name})`, the stars, the effect text and a NEW stamp when discovered.
- **Keyboard:** Space taps; Esc closes.

## Game (integrator) responsibilities
1. **State and migration.** See "Save data". Add the fields; leave `S.v` at 1, because the migration is additive.
2. **Ticking:**
   - On load, on returning to the tab, and every 60 s, call `PawGarden.advance(S.garden, {now, weatherAt, buddy})`. Store the result.
   - Turn events into toasts: "The peas are ready!", "Captain Fluff took one carrot and left an IOU." and "Pepper brought water for the spinach."
   - `weatherAt(key)` reuses the seeded formula in `weatherNow()` for an arbitrary key. Dev overrides apply only to the current period.
3. **Hotspots:**
   - `[data-hot="garden"]` in yard and `[data-hot="kitchen"]` in house, with lock checks.
   - Pass `scene('yard', {..., patch})` with `patch` set to `'empty'` (no crops), `'ready'` (any ready crop) or `'growing'`.
4. **Pip's Sprout Cart** (`[data-shop="sprout"]` in market): a modal in the shop style with 3 tabs.
   - **Seeds:** buy, with an In-season stamp.
   - **Sell crops:** by stars, showing the price multiplier.
   - **People gardens only:** the onion, garlic and grapes notes.
   - Pip's portrait is `prop('pip')`.
5. **Kibble Corner** gets a Pantry section (oats, rice, egg, chicken).
6. **Feeding dishes.** The Feed tray gets a Dishes row (`item(dish name)` with stars). Eating one:
   - Applies the effect × the star multiplier, plus the favourite bonus.
   - Applies the buff (`S.buff`), which replaces any older buff.
   - Limits: 2 dishes per dog per real day (`S.dishLog`). A 3rd dish gets "Treats are extras. Real vets say about a tenth of a dog's food. Kibble for the rest of today!"
   - Only the first Bond dish of the day gives Bond.
   - Shows the buff on the HUD as a small chip with the dish icon and the time left.
7. **Buff hooks:**
   - **`walk15`:** `durationSec + 15` on the next walk, then it is consumed.
   - **`dig1`:** `abilities.extraDig = true` on the next walk, then it is consumed. If the Acorn Cap is already worn, give +10 Happiness instead.
   - **`cool`:** for 24 h, skip the hot pose and hot penalty, and multiply walk energy by 0.75 in `finishWalkMod`.
   - **`warm`:** for 24 h, `isWarm()` returns true and Happiness decay is halved.
8. **Journal:**
   - **Garden tab:** 6 crop cards (art, seasons, days, harvest count, best stars) plus an "Open garden" button.
   - **Recipes tab:** 6 cards, with silhouettes for unknown ones, plus an "Open kitchen" button.
9. **Walk junk:** add `Onion` and `Grapes` junk entries (1 in 10 of junk rolls) with the safety note. The player gets 5 coins and no item.
10. **Dev panel:**
    - "Garden: +1 period" with a weather select (sunny, cloudy, rain, snow), which calls `advance` with `steps: 1`.
    - "Garden: all ready".
    - "Give seeds and pantry ×5".
11. **Audio:**
    - `setContext` place `'garden'` / `'kitchen'`.
    - Stingers `harvest`, `cooked` and `discover` through `PawAudio.stinger`.
    - New game sfx: `plant`, `water`, `pluck`, `chop`, `stir`, `sizzle`, `ding`, `squirrel`. Unknown names are still ignored.
12. **Fallback:** if `window.PawGarden` or `window.PawKitchen` is missing or throws, the hotspot toasts "The garden is having a nap. Try again later." Never crash.
