# Doodle Doggo (formerly Paw Haven)

A cozy browser game: adopt crayon-drawn dogs, care for them, walk a sketchbook town, grow a garden, and have puppy playdates with real coat genetics. Current version: **v2.11 "Tokyo Trip"** (also on claude.ai, where cloud save is off by design). History: `CHANGELOG.md`. Open issues: `TODO.md`.

**Read `PIPELINE.md` and `README.md` first.** Running parallel agents? Read `BUILDING.md` (roles, models and the cost rules). They describe the layout, the shared-scope rules, the lanes and the test runner. Two things there don't apply on this Mac: the `/home/claude/...` paths (they mean this repo root), and the multi-agent worktree workflow (`tools/wt.sh`), unless you're running parallel agents.

## Owner's standing rules (every session and every agent)

- **Usage limit: always resume.** If you stop at the usage limit, continue the task right after the reset, every time, without waiting for the owner. Before you stop, or as soon as you see the reset time, `send_later` yourself a resume for 2 minutes after the reset. The Game Manager also runs an hourly watchdog that resumes any stalled session.
- **Parallel teams are fine (owner, 17 Oct 2026, on the Max plan)**: run independent lanes, fix batches and reviews at the same time when it saves time. Push automatically once tests are green (details in `BUILDING.md`).
- **Fresh context when a session gets big (owner, 17 Oct 2026):** every session and subagent whose context passes about 300k tokens, with more than about an hour of work left, hands over to a fresh session at its next stopping point (handoff of 25 lines at most to its parent, which starts the replacement and archives the old one). Sessions can't `/compact` themselves, so this replaces it. Details: `BUILDING.md` rule 11.
- **Reports:** don't send the owner progress updates. Report only when the whole task is finished or when the owner asks.
- **Questions** go to the owner in the choice window with a recommendation first. With no answer in 5 minutes, take the recommendation.
- **itch.io: push each shipped release (owner, 17 Oct 2026).** After a release is on `main` and green, upload it: `node tools/itch.js` then `bash tools/itch_push.sh <version>`. The itch.io copy never shows the dev button or panel (`tools/itch.js` strips them); GitHub Pages and claude.ai keep it. Other itch.io development (page text, cover, screenshots) is still paused until the owner asks: don't build, refresh or upload itch.io files (`tools/itch.js`, `tools/itch_push.sh`, `brand/itch/`) as part of other tasks; it costs extra tokens. doodledoggo.app is an introduction site; players play on itch.io (https://an9ou.itch.io/doodle-doggo).
- **5-minute rule for every session and subagent (owner, 16 Oct 2026):** any question or approval the owner leaves unanswered for 5 minutes goes with the recommended choice. A permission prompt can't be approved on the owner's behalf, so when one waits 5 minutes, take the recommended path that doesn't need it and keep going. Prefer paths that need no approval prompt at all.

## Save data

`localStorage['pawhaven_proto_v1']` holds `S` (schema `v: 1`). The cloud stores exactly that JSON (`saves` table); sync bookkeeping lives in `pawhaven_cloud_v1`. Migrate **additively** in `migrate()` (`game/src/00_core.js`): give new fields defaults, never bump `v`, never drop fields. Old saves must always load. Prototype speed-ups: `BOOST = { coins: 2, bond: 3, nap: 6 }`, 1 game hour = 1 real minute, 1 real day = 1 dog month.

## Design rules (from the proposal; don't break them)

- **Nothing bad ever happens.** No fail states, no sickness, death or running away.
- **No selling dogs, ever.** Puppies are adopted out free to named families. Sparkle is cosmetic only, never paid.
- **Real welfare and food safety.** No double merle, no relatives, age and season limits, rest between litters. Nothing toxic to dogs can be planted, cooked or fed. Blocks are short, kind, two-sentence lessons.
- **Look.** A detailed pencil-sketchbook world with **deliberately crude crayon dogs**. The ugly dogs are the joke.
- **Words.** Never "breed" as a verb, "stud", "litter price", "sell" (for dogs). The build rejects "nintendo", "pokémon" and "animal crossing".
- **Economy.** Walks are the main income (~100 a day); the garden stays below it.
