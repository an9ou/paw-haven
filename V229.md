# v2.29 "Story mode" (contract), part 1

Owner's request and choices: 11 Nov 2026 (animated in-game scenes, Skip after 3 s, a Memories album, a chaptered main story alongside free
play). Design: `docs/design/story-mode.md`. Code: `game/src/57_scenes.js` (scene engine, tag `sc`, hook `window.__paw.sc`),
`game/src/57b_story.js` (story, tag `sm`, hook `window.__paw.sm`), `game/css/59_scenes.css`. Suite: `v229_story`.
Small hooks elsewhere: `LV_MILE.story` (`51_levels.js`, story XP outside the daily cap), `tick()` holds while a scene plays
(`21_time_loop.js`), `v229Fields` in `freshState()` / `migrate()` (`00_core.js`), Story in the phone "..." menu (`22c_phone_shell.js`).
Rules kept: nothing bad ever happens, no fail state, no deadline, no FOMO (nothing runs out), free play unchanged, walks stay the main income,
every fill inside its outline (the crayon book draws each fill from the same path as its outline), no new image files.

## 0. Switch and gates

`SM_LIVE = true`, `smOn()`. Under the harness (`navigator.webdriver`) the story needs `prefs.smTest` and the automatic scenes `prefs.scTest`,
so the older suites see nothing new. The save field is always added. No NEWS entry and no translations in this branch: every string is
`tt('sm.*' | 'sc.*', 'English')`.

## 2. Save field (additive in `migrate()` and `freshState()`; `v` stays 1)

`v229Fields(s, fresh)`:

```
S.story = {
  ch: 0,          // the open chapter; 0 = not started yet, SM_N + 1 = the whole book done
  p: {},          // task id -> progress (never above the task's n)
  t: {},          // task id -> Japan date it was done and paid ('old' = earned before v2.29, paid by the catch-up letter)
  c: {},          // chapter number -> Japan date it was finished and paid ('old' as above)
  m: {},          // scene id -> Japan date it was unlocked (the Memories album)
  w: {},          // scene id -> 1 once watched (played to the end, skipped, or watched again from the album)
  q: [],          // scene ids waiting to play by themselves, in order
  from: 'fresh' | 'old', // a save made with v2.29 or before it
  cu: 0 | 1,      // the old-save catch-up done
  cuN: n          // chapters the catch-up gave (for its scene)
}
```

A broken or missing `story` is rebuilt; existing fields are kept as they are.

## 3. Start and catch-up

- Start (`smStart`, every second while `smOn()`): not on the title or adoption, not while Puppy's first day with Gerald runs.
  A fresh save: `ch = 1` and the `prologue` queued.
- An old save (`from: 'old'`), once (`cu`): the chapters it has earned, in order, stopping at the first one not earned:
  chapter 1 = any walk or any dog at Bond 2+; chapter 2 = 5+ walks and a treasure found. Earned chapters and their tasks are marked `'old'`,
  their scenes and the prologue go into the album (not played, not watched), the first-visit scenes go in too when the place is in
  `S.lv.seen` or the save has 3+ walks. XP for those pages at once (`lvGain('story')`), coins in one kept letter from Gerald
  ("The story so far", id `sm_catchup`, a Collect gift) capped at `SM_CATCH_CAP` = 150, no Bond. The `catchup` scene is the only one queued.
  Nothing earned: chapter 1 and the prologue, no letter.

## 5. Tests (`node game/run_tests.js v229_story`, group `all`)

1. Migration: a new save starts after the first day and the prologue plays by itself; old-save defaults (`ch 0`, `from 'old'`), existing
   fields kept, a broken field rebuilt; an old save with nothing earned gets chapter 1 and the prologue, no letter; an advanced old save
   through Continue: v 1, nothing dropped, chapters 1-2 `'old'`, chapter 3 open, the letter (150 coins, kept), the XP once, the scenes in the
   album unwatched, only the catch-up plays, never twice.
2. Tasks from real actions (a real feed, a real pet, a real trip to Sunny Park) and the act bus; pets stop at 3/3; an early walk does not
   count; the last task and the chapter pay once (+50 coins, +40 XP, +13 Bond); chapter acts again pay nothing; a second trip pays and
   queues nothing; three scenes queue in order; the Story page (8 chapters, 2 done, chapter 3 "still being written").
3. Scenes: one plays by itself, no Skip at the start, Skip after about 3 s, the game clock stops, every scene 10-15 s; played to the end
   = watched and in the album and never queued again; the queue plays in order (8 s apart); Memories lists the watched ones, Watch replays
   and the album comes back.
4. No stacking: waits under the Story sheet and under the What's new sheet, then plays; a second scene cannot start over one that plays.
5. Motion off: the dog and the camera stay still within a shot; with Motion on the dog walks in.
6. Fit at 360x640 and 1280x720: the scene covers the stage, the picture has room, the caption fits, Skip is a 44 px tap; the Story sheet
   inside the screen with 44 px tabs and no overflowing text; Story in the phone menu, the book button on the desktop top bar.
